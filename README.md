# nenmatsu-collector

年末調整の申告データを、紙ではなくデータとして集めるためのツールです。
職員が入力する画面と、人事担当者が集約・検証する画面の2本で構成されています。

**インストール不要。管理者権限不要。通信不要。** 各HTMLファイルをブラウザで開くだけで動作します。

- 公開ページ：https://toyfer.github.io/nenmatsu-collector/
- 職員用：`staff.html`
- 人事用：`admin.html`

## これは何か

紙の申告書を配って回収し、人事が全件を目視で検算して修正指示を出す、という流れを置き換えるためのツールです。
狙いは「人事が毎回手で直す」を「機械が先に例外を出す」に変えることです。

| ファイル | 役割 |
|---|---|
| `index.html` | 入口。2つのツールへのリンクと注意事項 |
| `staff.html` | 職員用。入力、検証、下書き保存、確認書の印刷、CSV出力 |
| `admin.html` | 人事用。集約、検証、未提出者の抽出、前年差分レビュー、CSV出力 |
| `samples/` | 動作確認用のサンプル（氏名・住所はすべて架空） |
| `docs/verification.html` | 信頼性の担保方法と検証手順、税務上の確認事項 |

## 動作要件

- モダンなWebブラウザ（Edge / Chrome / Firefox / Safari のいずれか）のみ。
- サーバー不要。インターネット接続不要。オフラインで動作します。
- ファイルを共有フォルダに置いて、職員がブラウザで開く運用が最も摩擦が少なくなります。

## 使い方（職員）

1. `staff.html` をブラウザで開きます。
2. 基本情報と各申告書の内容を入力します。
3. 「入力チェック」で誤りを確認します。
4. 必要に応じて「下書きを保存」でファイルに残します。翌年はこれを「下書きを読込」で読み込むと、変更点だけ直せます。
5. 「確認書を印刷」で確認書を出し、自署・押印します。
6. 「提出用CSVを出力」し、人事（給与担当）へ提出します。

## 使い方（人事）

1. `admin.html` をブラウザで開きます。
2. 職員から集めたCSV（またはJSON）をまとめて選択します。チェックサムは自動照合されます。
3. 職員名簿CSVを読み込むと、未提出者が抽出されます。
4. 前年のCSVを読み込むと、金額の桁違いや扶養人数の急変がフラグされます。
5. 「要確認リストをCSV出力」で、指摘のある人だけを職員に返します。
6. 「給与システム取込用CSVを出力」で、給与システムへ渡すデータを作ります。

## このツールが行わないこと

- **控除額・税額の計算は行いません。** 金額は事実（払込額・見積額）として集めるだけです。控除額の判定と税額の計算は給与システム側で行ってください。
- マイナポータル連携による控除証明書データの取得はできません。
- 法定調書・源泉徴収票の作成はできません。
- 申告内容の確定は行いません。最終判断は担当者の確認によります。

## データ形式

提出CSVは34列です。列の並びがすべての基準であり、`staff.html` と `admin.html` で同じ順序に保つ必要があります。

- 1〜4列目：レコード種別、ツール版、様式年度、提出日時
- 5〜7列目：職員番号、氏名、所属
- 8〜16列目：扶養控除等（異動）申告書の項目
- 17〜18列目：基礎控除申告書、配偶者控除等申告書、所得金額調整控除申告書
- 19〜26列目：保険料控除申告書の項目
- 27〜29列目：住宅借入金等特別控除の項目
- 30〜31列目：本人確認、備考
- 32〜33列目：チェックサム方式、チェックサム

扶養親族の明細は、`氏名|続柄|生年月日|同居区分|所得見積額|住所` を `;` で連結して1セルに格納します。

## 改造の勘所

- 項目を増減する場合は `staff.html` と `admin.html` の両方の `COLS` を同じ順序で揃えてください。
- 入力チェックの条件は、両ファイルの `validate()` にあります。
- 年度を変えるときは `TOOL_VERSION` と `FORM_YEAR` を更新してください。
- 見た目は各ファイルの `<style>` に完結しています。

## 注意

本ツールは非公式の試作です。国税庁およびいかなる自治体・団体とも関係ありません。
実在の個人情報は含みません。サンプルの氏名・住所はすべて架空のものです。

本番運用の前に、`docs/verification.html` に記載した確認事項（情報管理、税務上の位置づけ、様式との突合、回帰テスト）をすべてクリアしてください。
